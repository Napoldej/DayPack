2Core Components

Reusable building blocks. Each component declares its purpose, variants, anatomy, and the tokens it consumes — so a developer can ship it without ambiguity.

Button

<Button />
Purpose
Trigger primary actions, navigate flows, confirm destructive intent.
Variants
  • primary — orange, white text, brand shadow. One per screen.
  • secondary — peach tint, deep-orange text. For paired choices.
  • ghost — transparent. Tertiary actions like Cancel.
  • danger — red tint. Destructive (delete loadout).
  • States: default · pressed · disabled · loading
  • Sizes: sm 36px · md 50px · lg 54px
Structure
Container → [Leading icon? · Label · Trailing icon?]. Icons 18 px. Label uses Headline (17/600).
Tokens
BG: --orange / --orangeSoft / transparent. Radius: r-md sm · r-xl md+. Shadow: brand.

Checklist Item

<ChecklistItem />
Notebook
Always
Water Bottle
Protein Shake
Don't forget
Purpose
Single packable item — the core building block of every checklist.
Variants
  • State: unpacked · packed · skipped · high-priority
  • Tags: Always · Optional · Don't forget
  • Density: compact (preview) vs full (checklist screen)
Structure
Row → [Checkbox · IconTile · {Label + optional Reason} · Pill(s)]. Tap target ≥ 56 px. Swipe-right reveals quick-pack action.
Tokens
BG packed: --greenSoft · BG hi-pri: #FFF7F4 · Strikethrough: --ink4. Padding: space-3.

Purpose
Profile representing a kind of day. Drives auto-suggestion on the Today screen.
Variants
  • default · active (today) with brand border + corner badge
  • preset in onboarding/empty state — denser, no metadata
  • compact in Up Next list (no preview row)
Structure
Card → [IconTile (48–56 px, tinted bg) · {Title (Title 2) · Subtitle (Subhead)} · trailing badge/chevron] + optional bottom row [3 mini icons + "+N more"].
Tokens
Radius: r-xl (22). Padding: space-4. Border (active): 1.5px var(--orange).

Progress Bar & Ring

<Progress />
3 of 6 packed50%
Trip Planner — Carry-on
Walk-out hero · ring variant.
Animates on value change (220 ms ease-out).
Purpose
Show packing completion at-a-glance. Drives the "ready to leave" mental model.
Variants
  • bar.lg — 10 px, gradient fill, on hero card
  • bar.sm — 5–6 px, single-tone, in list rows
  • ring — 64 px, used in walk-out hero
Structure
Track (track color) + Fill (gradient/solid). Optional label row above. Animates on value change with 220 ms ease-out.
Tokens
Track: #F0EAE2 / --bgGrouped. Fill: linear-gradient(--orange → --orangeDeep).

Binary on/off setting. Used for recurring items, reminders, item priority.

  • Color of "on" matches context: --orange default · --green when paired with success semantics
